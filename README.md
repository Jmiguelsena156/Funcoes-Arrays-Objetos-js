# Arrays, Objects e Funções

* Arrays: 
   * Principais funções:
      * `.push(valor)`: 
      * `.shift()`;
      * `forEach()`;
      * `map()`;
      * `filter()`;
      * `reduces()`;

* Objets:
   * Principais caracteristicas:
      ```js
      let aluno = {nome: "Jose Miguel", idade: 18};

      // acessar
      console.log(aluno.nome);
      console.log(aluno["idade"]);
      
      // criar  e modificar
      aluno.altura = 1.78;
      aluno.idade = 18;
      ```

* Funções
   * Principais caracteristicas:
      ```js
      // Sem retorno
      function informar() {
         console.log("Hello World");
      }

      // Com retorno
      function somar(a, b) {
         return a+b;
      }

      ```
